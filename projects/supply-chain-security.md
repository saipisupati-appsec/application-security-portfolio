## Scope

This project maps how third-party packages enter a product and applies controls across selection, consumption, build, and remediation.

## Focus areas

- Dependency inventory and SBOMs
- Vulnerability and license-aware triage
- Package repository policies and trusted sources
- Build provenance and artifact integrity
- Timely remediation with owner visibility
