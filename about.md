I am **Sai Kumar Pisupati**, an Application Security Engineer focused on making secure delivery a reliable engineering practice—not a late-stage review.

## Focus areas

- Secure SDLC and developer enablement
- Threat modeling and security architecture
- SAST, DAST, SCA, secret scanning, and risk-based remediation
- API, cloud, IaC, and software supply-chain security
- CI/CD security gates and security automation

## How I work

I prefer security controls with clear ownership, useful findings, and measurable outcomes. That means bringing security into design discussions, automating routine checks in the delivery pipeline, and giving engineering teams the context to act on risk.

All portfolio examples are sanitized or recreated for demonstration. They contain no confidential information, production data, or credentials.
