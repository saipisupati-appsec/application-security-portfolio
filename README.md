## Development

### Prerequisites

* Node.js
* npm
* Git

### Clone the repository

```bash
git clone https://github.com/saipisupati-appsec/application-security-portfolio.git
cd application-security-portfolio
```

### Install dependencies

```bash
npm ci
```

### Start the development server

```bash
npm run dev
```

The development server will normally be available at:

```text
http://localhost:4321
```

### Build the production site

```bash
npm run build
```

### Run Astro validation

```bash
npx astro check
```

### Run TypeScript validation

```bash
npx tsc --noEmit
```

## Deployment

The portfolio is deployed as a static Astro site using **GitHub Pages**.

The deployment workflow is managed through GitHub Actions.

High-level deployment flow:

```text
Git Push
   │
   ▼
GitHub Actions
   │
   ├── Install dependencies
   │
   ├── Run validation
   │
   ├── Build Astro application
   │
   └── Generate static site
          │
          ▼
     GitHub Pages
```
