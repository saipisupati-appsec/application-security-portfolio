# Application Security Portfolio

Portfolio of Sai Kumar Pisupati, Application Security Engineer.

The site presents work across Application Security, Product Security, Secure SDLC, threat modeling, secure design and code reviews, DevSecOps, software supply-chain security, cloud security, vulnerability management, and security automation.

## Stack

- Astro
- TypeScript
- Tailwind CSS
- Astro Content Collections with Zod validation
- Three.js for the existing responsive hero visual

## Development

```bash
npm install
npm run dev
```

Build the static site with:

```bash
npm run build
```

Run Astro diagnostics with:

```bash
npx astro check
```
